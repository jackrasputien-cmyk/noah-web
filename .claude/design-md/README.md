# Referensi DESIGN.md

Contoh DESIGN.md dari https://github.com/VoltAgent/awesome-design-md (MIT). Isinya gaya visual merek terkenal
(warna, font, spasi) yang bisa dibaca agen AI. Koleksi lengkap ada 70+ merek di repo itu.

Cara pakai: salin satu file jadi `DESIGN.md` di akar project, lalu minta
"Bikin halaman ini pakai DESIGN.md". Hanya satu DESIGN.md aktif dalam satu waktu.
Ini referensi gaya, bukan pengganti panduan desain milik project sendiri.
